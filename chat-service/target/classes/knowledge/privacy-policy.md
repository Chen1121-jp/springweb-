# 隐私政策

> 基于《淘宝网基本功能隐私政策》《淘宝平台隐私政策（境外版）》整理。

---

## 一、收集的个人信息

### 必要信息（不提供将无法使用基本服务）

| 用途 | 收集的信息 |
|------|-----------|
| 账号注册与登录 | 手机号码 |
| 下单与订单管理 | 收货人姓名、收货地址、联系电话、订单信息（商品名称、数量、金额、时间） |
| 支付 | 支付账号、支付时间、支付金额、支付方式 |
| 商品交付 | 收货人姓名、收货地址、联系方式 |
| 客服与售后 | 账号信息、订单信息（核验身份） |

### 额外收集的信息

| 用途 | 收集的信息 |
|------|-----------|
| 跨境交易清关 | 身份证件信息（身份证号、护照号等） |
| 实名/实人认证 | 身份证信息 |
| 开具发票 | 发票抬头、纳税人识别号、接收邮箱 |
| 物流推荐/附近店铺 | 地理位置信息 |
| 个性化推荐 | 浏览记录、订单历史记录 |

---

## 二、信息使用目的

- **完成交易：** 处理订单、支付结算、商品配送
- **客服与售后：** 核验身份、处理退换货和争议纠纷
- **交易安全：** 判断交易是否存在异常，保障账户安全
- **服务通知：** 发送订单状态、物流信息、身份验证、安全验证等必要通知
- **个性化推荐：** 基于浏览和购买记录推送可能感兴趣的商品和活动
- **法律合规：** 履行法定义务（如交易记录保存、税务申报等）

---

## 三、信息共享

### 与第三方共享的必要信息

| 第三方 | 共享信息 | 目的 |
|--------|----------|------|
| 卖家/商家 | 订单信息、收货信息 | 商品履约、售后服务 |
| 支付机构（支付宝等） | 账号信息、订单支付信息 | 完成支付 |
| 物流服务商（菜鸟等） | 收货人姓名、地址、联系方式、订单信息 | 商品配送 |
| 客服外包商 | 账号信息、订单信息 | 提供客服支持 |

### 共享原则

- 仅共享**履约所必需的最小范围**内的个人信息
- 与合作方签订数据处理协议/保密条款
- 要求接收方采取安全措施保护信息

---

## 四、信息存储

- **存储地点：** 原则上在中国境内存储
- **存储期限：**
  - 交易信息（商品/服务信息、交易记录）：自交易完成之日起不少于**3年**（《电子商务法》要求）
  - 其他个人信息：在达成收集目的所需期限内保留
- **跨境传输（跨境电商场景）：**
  - 订单/收货信息可能传输至境外卖家/物流方
  - 采取去标识化处理、加密传输、签订数据处理协议等措施
  - 需取得用户的单独同意（如适用）

---

## 五、用户权利

| 权利 | 说明 |
|------|------|
| 访问权 | 可查看已收集的个人信息 |
| 更正权 | 可修改或补充不准确的个人信息 |
| 删除权 | 可申请删除个人信息（法律要求保留的除外） |
| 撤回同意 | 可撤回对个人信息收集和使用的同意 |
| 注销账户 | 可申请注销淘宝账号 |
| 拒绝广告 | 可通过短信退订、邮件退订或 App 设置关闭个性化推荐 |

### 操作路径

- **查看/修改个人信息：** 我的淘宝 → 设置 → 个人资料
- **订单信息：** 我的淘宝 → 我的订单
- **关闭广告推送：** 我的淘宝 → 设置 → 消息通知
- **关闭弹窗推送：** 设备"设置" → 关闭淘宝通知权限
- **注销账户：** 我的淘宝 → 设置 → 账户与安全 → 注销账户

---

## 六、安全保障措施

- 对数据中心实施物理访问限制
- 对数据和系统实施逻辑访问控制
- 限制员工、代理、承包商和第三方访问个人数据的权限
- 采取加密传输、去标识化等安全技术手段
- 定期评估和审计数据处理方的安全能力

---

## 七、未成年人保护

- 淘宝平台主要面向成年人
- 未成年人在监护人同意和指导下使用
- 收集到未成年人信息后，监护人可联系客服要求删除

---

## 八、常见问题

**Q: 淘宝会售卖我的个人信息吗？**
A: 不会。淘宝不会将个人信息出售给任何第三方，仅在与服务相关的必要范围内共享。

**Q: 如何退订营销信息？**
A: 通过短信中提供的退订方式回复退订；或在 App 中"我的淘宝 → 设置 → 消息通知"进行关闭。

**Q: 注销账户后信息会被删除吗？**
A: 注销后淘宝将停止收集并使用您的个人信息，并对已持有的信息进行删除或匿名化处理，但法律要求留存的信息（如交易记录）除外。

**Q: 跨境购物时我的信息会传到国外吗？**
A: 购买跨境商品时，您的订单和收货信息可能会传输给境外卖家或物流商。淘宝会依法采取去标识化、加密等措施保护您的信息。
