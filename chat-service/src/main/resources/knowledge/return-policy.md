# 退换货政策

> 基于《淘宝网七天无理由退货规范》《淘宝平台争议处理规则》《消费者保障服务协议》整理。

---

## 一、七天无理由退货

### 适用范围

买家购买带有"7天无理由退货"服务标识的商品，自**签收商品之日起七天内**（物流签收次日零时起计，满168小时），可向卖家发起七天无理由退货申请。

### 不适用七天无理由退货的商品

| 类型 | 示例 |
|------|------|
| 买家定作的定制类商品 | 个性定制、设计服务 |
| 鲜活易腐类商品 | 鲜花绿植、水产肉类、新鲜蔬果、宠物、速冻食品 |
| 在线下载或拆封的数字化商品 | 网游、话费、数字阅读、电子凭证 |
| 交付的报纸、期刊 | — |
| 一经激活或试用后价值贬损较大的商品 | 智能设备、商用厨电、黄金 |
| 拆封后影响人身安全或健康的商品 | 保健品、贴身用品、成人用品、酒水 |
| 服务类商品 | 本地服务、代购服务 |
| 二手/竞拍商品 | — |

### 商品完好标准

**通用完好标准：**
- 商品保持原有品质、功能，配件齐全（吊牌、说明书、三包卡等）
- 买家基于查验需要而拆开包装或合理调试不影响商品完好
- 超出查验和确认需要的过度使用，导致商品价值贬损较大的，视为不完好

**包装完好标准：**
- 商品原包装未缺失，包装整体结构完整
- 运输或拆卸过程中适度的变形、污渍、局部破损不认定为包装不完整
- 具有防伪性、唯一性、收藏价值的特殊包装，卖家需事前显著明示保护要求

### 运费规则

| 场景 | 运费承担 |
|------|----------|
| 商品包邮 | 买家仅承担退回运费 |
| 商品未包邮或附条件包邮 | 买家承担所有运费（另有约定除外） |
| 赠品/发票遗失 | 赠品遗失作折价处理，发票遗失由买家承担相应税款 |
| 买家滥用会员权利 | 所有运费由买家承担 |

## 二、质量问题退换货

### 保障期限

- **付款后至交易成功前**：可申请"退货/退款"，款项尚未拨给卖家
- **交易成功后15天内**：可申请"申请售后"，淘宝可划拨卖家保证金先行赔付
- **超过15天**：超出保障期限，淘宝不再受理相关维权请求（三包商品除外）

### 卖家责任导致退货

- 卖家承担**第一次发货及退货运费**
- 买家需提供有效凭证：实物照片、旺旺聊天记录截图、质检报告等
- 卖家拒绝或无法联系时，淘宝可介入处理，判定维权成功后划拨卖家保证金赔付

## 三、消费者保障计划

- **保障范围：** 付款后未收到商品 / 收到商品存在质量问题 / 商品与描述不符
- **保障期限：** 自付款时至交易成功后15天内
- **保障方式：** 卖家缴纳保证金，淘宝可扣划保证金对买家进行先行赔付
- **保障标识：** 带有消费者保障服务标识的商品才享受该服务

## 四、退货退款时效

| 场景 | 处理时效 |
|------|----------|
| 未发货订单（≤200元且付款2小时内） | 0秒退款 |
| 未发货订单（其他情形） | 卖家需在24小时内响应 |
| 已发货订单 → 买家申请退货 | 卖家需在系统限定时效内提供退货地址 |
| 买家退货后 → 卖家确认 | 系统限定时效内确认收货并退款 |
| 卖家逾期不处理 | 系统默认同意退款 |

## 五、常见问题

**Q: 退货时赠品需要退回吗？**
A: 需要一同退回。赠品遗失或破损作折价处理；发票遗失不影响退货，但买家需承担相应税款。

**Q: 什么情况下退货申请会被拒绝？**
A: 超过保障期限、商品不符合完好标准、商品属于不适用七天无理由退货的品类、买家滥用会员权利等。

**Q: 卖家拒绝退款怎么办？**
A: 可在维权申请中点击"申请淘宝客服介入"，淘宝客服会介入处理并作出判定。
